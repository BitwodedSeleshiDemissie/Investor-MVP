Formula Review Final

Final formula reference for the dashboard calculations, showing the Excel tab source and the calculation logic used for each metric.

Formula Reference

Metric Formula / Excel Source Notes
Total Portfolio Value Portfolio Metrics tab: Total Portfolio Value Used as the main NAV / portfolio value displayed on the dashboard.
Capital Committed Portfolio Metrics tab: Total Invested Capital Used as the total capital contributed / invested capital figure.
Return Since Entry Portfolio Metrics tab: (Total Portfolio Value - Total Invested Capital) / Total Invested Capital Simple return metric, separate from IRR and TWR.
MOIC Portfolio Metrics tab: (Total Portfolio Value + Total Income) / Total Invested Capital Shows multiple on invested capital including income received.
Current Yield Portfolio Metrics tab: Total Income / Total Portfolio Value Uses income received relative to current portfolio value.
Distributions Trade Log tab: sum Net Amount for Dividend, Coupon, Distribution, Sec. Lending Income rows are summed using net amount.
Asset Allocation Holdings tab + Portfolio Metrics tab: Asset Class Market Value / Total Allocation Value Uses holdings market value by asset class, with cash from Portfolio Metrics.
Investor IRR IRR Analysis tab + Portfolio Metrics tab: XIRR(investor cash flows + terminal portfolio value) Deposits are treated as negative cash flows; withdrawals and terminal value are positive.
Company / Fund IRR IRR Analysis tab + Portfolio Metrics tab: XIRR(portfolio cash flows + terminal holdings market value) Uses portfolio-level cash flows and terminal holdings market value.
Annualized Return Portfolio Metrics tab: Annualized Return (TWR) Read directly from the workbook.
Volatility Monthly Returns tab: StdDev(monthly returns) * sqrt(12) Annualized from monthly return volatility.
Sharpe Ratio Portfolio Metrics tab + Monthly Returns tab: (Annualized Return - Risk-Free Rate) / Volatility Uses annualized return, risk-free rate, and annualized volatility.
Max Drawdown Monthly Returns tab: lowest drop from peak using monthly return index Based on the compounded monthly return series.
If Excel sheet names, column names, labels, or cell positions change in future versions, the dashboard mapping should be reviewed.
